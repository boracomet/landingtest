Gontact Form

Contact forms: form tags, mail, validation, spam protection (Contact Form 7).

Gontact Form is Pursae's native (compiled-in) clone of Contact Form 7 (studied at CF7 6.2.3, rocklobster-in/contact-form-7, plus contactform7.com docs). Like Classic Editor, WPGo Cache and Golementor it is listed under Plugins, off on a fresh install, and while off it adds nothing: no menu, no screens (404/403), no REST namespace, no shortcode, no block, no front-end assets.

Legend: ✅ implemented · ◐ implemented differently / partly · ✗ left out (with the reason).

Forms are wrapped with wpcf7_autop (paragraphs/line breaks) like CF7 (WPCF7_AUTOP).

Image CAPTCHA ([captchac] / [captchar])

CF7 needs the Really Simple CAPTCHA plugin for these tags; Gontact Form generates the images itself, in pure Go:

  • Challenge: 4 characters from ABCDEFGHJKLMNPQRSTUVWXYZ23456789 (no 0/O, 1/I/l), drawn with the Go Bold font (golang.org/x/image/font/gofont, BSD licence, compiled in) at 3× the displayed size, each character rotated up to ±17° and shifted a little, over noise dots and lines in tints between fg and bg.
  • Storage: table gontact_captcha (migration 0012_gontact_captcha.sql): random numeric prefix → HMAC-SHA256 of prefix + answer (keyed with gontact_form_secret) and the PNG. The answer itself is never stored.
  • Image URL: /wp-content/gontact-captcha/{prefix}.png, Cache-Control: no-store (the page cache never keeps it); 404 for unknown, used or expired prefixes, and while the plugin is off.
  • Markup (CF7's): <input type="hidden" name="_wpcf7_captcha_challenge_{name}" value="{prefix}"> + <img class="wpcf7-form-control wpcf7-captchac wpcf7-captcha-{name}" width height alt src>; the answer field is <input class="wpcf7-form-control wpcf7-captchar wpcf7-text" autocomplete="off"> in the usual wrap. The image has a descriptive alt, and a refresh control (.wpcf7-captcha-refresh, a span role="button" so it never steals the <label> of the answer field) that the script shows and that fetches a new image.
  • Validation: the answer is canonicalized (case and blanks ignored) and checked against the posted prefix; the challenge is deleted on its first check, right or wrong (single use). Wrong, reused, expired or missing → captcha_not_match "Your entered code is incorrect." in invalid_fields (editable on the Messages tab).
  • Expiry: an hour. The hourly core event gontact_captcha_cleanup deletes older rows.
  • Page cache: a cached page carries one stale challenge; with wpcf7.cached the script resets the form on load and the refill endpoint (GET …/contact-forms/{id}/refill, never cached) returns {"captcha": {"your-captcha": "…/{new prefix}.png"}}, which the script puts into the image and the hidden field. The feedback response carries the same captcha key, so every submission shows a new image. CF7's own front-end script works unchanged against this response (it reads the prefix from the URL).
  • Accessibility: there is no audio CAPTCHA. The tag generator says so and points to the [quiz] tag as the accessible alternative (a text question works with screen readers).

9. Not ported (summary)

Flamingo, Akismet, Constant Contact, Brevo, Stripe, data: option lists, reflection/listo, translations (UI is English), CF7's welcome panel and promotional notices, multisite bits.

Piece Where
