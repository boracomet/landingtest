Built-in plugins

The plugins that ship inside Pursae and what each of them does.

These plugins are compiled into the binary. Like Classic Editor and WPGo Cache they are listed on Plugins, start off on a fresh install and add nothing to the site while off. Each page is the feature inventory of the plugin: what it does and what it leaves out.

  • SEO-Go: SEO in one plugin: the union of Yoast SEO Premium and Rank Math Pro.
  • ACF-Go: Custom fields: field groups, field types, location rules, options pages, blocks and REST (Advanced Custom Fields PRO).
  • Goocommerce: E-commerce: a WooCommerce clone with 14 built-in modules, store themes and the wc/v3 and Store REST APIs.
  • HeadlessGo: Headless CMS: content types, content manager, REST and GraphQL delivery API, webhooks and preview.
  • GoCDN: Object storage offload, CDN rewriting, on-the-fly images and cache purging.
  • Gontact Form: Contact forms: form tags, mail, validation, spam protection (Contact Form 7).
  • Golylang: Multilingual sites: languages, translated content and strings, menus and the language switcher (Polylang Pro).
  • AdminSecGo: Login security: two-factor, hidden login URL, throttling, audit log, password rules.
  • Gooike: Cookie consent: banner, scanner, consent log and script blocking.
  • Maintenance-Go: Maintenance and coming-soon mode (clone of the Maintenance plugin by WebFactory).
  • WPGO Mail SMTP: Outgoing mail: mailers, smart routing, email log, reports and alerts (WP Mail SMTP).
