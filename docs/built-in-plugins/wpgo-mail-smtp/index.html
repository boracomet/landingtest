WPGO Mail SMTP

Outgoing mail: mailers, smart routing, email log, reports and alerts (WP Mail SMTP).

WPGO Mail SMTP is Pursae's native (compiled-in) clone of WP Mail SMTP by WPForms / Awesome Motive (Lite and Pro), the most installed mail plugin for WordPress. Sources: the wordpress.org listing (wordpress.org/plugins/wp-mail-smtp), the wpmailsmtp.com documentation, and the plugin source (awesomemotive/wp-mail-smtp, src/Options.php for option keys and the WPMS_* constants).

Like Classic Editor, WPGo Cache and Golementor it ships inside the binary, is listed on Plugins › Installed Plugins and Add Plugin, starts inactive and adds nothing (menu, routes, notices, dashboard widget, mail behaviour) while inactive. While it is inactive, wp_mail() keeps working exactly as before: the WPGO_SMTP_* environment variables, or .eml files in WPGO_MAIL_DIR on development sites.

Legend: ✅ implemented · ◐ implemented with a Pursae specific difference · — left out (reason given).

1. How it plugs into Pursae

WP Mail SMTP Pursae
Replaces wp_mail()'s PHPMailer instance (phpmailer_init) Server.mailer() attaches a mail.Transport to the mail.Mailer while the plugin is active. Every sender goes through it: the queued wp_mail job (core notifications) and direct Send calls (Golementor form e-mails). ✅
Plugin data in options wp_mail_smtp, wp_mail_smtp_* One JSON option wp_mail_smtp (same group/key names: mail.from_email, smtp.host, mailgun.api_key, …), activation switch native_wp_mail_smtp ✅
Email log in {prefix}wpmailsmtp_emails_log, debug events in {prefix}wpmailsmtp_debug_events Tables wpmailsmtp_emails_log, wpmailsmtp_debug_events (migration 0011_wp_mail_smtp.sql) ✅
Secrets stored in plain text in wp_options (or a constant) Secrets (SMTP password, API keys, client secrets, OAuth tokens, Twilio token) are AES-256-GCM encrypted with a key derived from the server secret (WPGO_SECRET / auth_secret), stored as enc:v1:…, never printed back into a form (the field shows a "saved" placeholder and a Remove checkbox; leaving it blank keeps the saved value) ◐ stronger than upstream

3. Settings › General (admin?page=wp-mail-smtp)

Setting Behaviour
From Email + Force From Email Address used for every message. Without Force, a message that sets its own From (e.g. a Golementor form's "From Email") keeps it; with Force it is always replaced ✅
From Name + Force From Name Same for the display name (default: site title) ✅
Return Path ("Set the return-path to match the From Email") The SMTP envelope sender (bounces) is the From Email; when a message keeps its own From (not forced) the envelope follows it only with Return Path on ◐ (no PHP mail())
Mailer Default (none), Other SMTP and every mailer below. Pro-only mailers are included (no license) ✅
Other SMTP: SMTP Host, Encryption (None / SSL / TLS), SMTP Port (25 / 465 / 587 suggested per encryption), Auto TLS, Authentication, SMTP Username, SMTP Password Native net/smtp client; SSL = implicit TLS, TLS = STARTTLS required, None + Auto TLS = STARTTLS when the server offers it; AUTH PLAIN (LOGIN fallback when the server only advertises LOGIN) ✅
Default (none) = PHP mail() Pursae's built-in transport: WPGO_SMTP_* env SMTP, or .eml files ◐
Backup Connection (Pro) Pick one Additional Connection; when the primary connection fails the message is retried once through it; the log records which connection delivered it ✅
Rate limiting (Pro, per minute/hour/day/week/month) Under Misc. Sends are counted in wpmailsmtp_rate; over a limit the message is re-queued as a wp_mail job for when the window allows it (a form's own From is not kept on the re-queued copy) ✅
Optimized email sending (Pro, background queue) Always on in Pursae: core e-mail is already sent by the job runner ◐

5. Additional Connections & Smart Routing (Pro)
Additional Connections: any number of extra mailer configurations, each with a name, From Email/Name and mailer settings; Send test per connection ✅
Smart Routing: ordered routes "Send with connection X if" condition groups (AND inside a group, OR between groups); properties Subject, Message, From Email, From Name, To, Reply-To, Initiator; operators is / is not / contains / does not contain / starts with / ends with / regex / does not match regex. First matching route wins, else the primary connection ✅

9. Email Controls (Pro) (tab=control)

Toggles for the notification e-mails Pursae core sends (identified by their subject): comment moderation / new comment to author; admin e-mail change confirmation; user e-mail change request; password reset request, password changed (to admin), new user registration (admin + user); personal data confirm request / action confirmed / export ready / erasure fulfilled. Disabled types are dropped silently. Automatic core/plugin/theme update e-mails don't exist in Pursae. ✅

13. Constants → environment variables

WPMS_ON=true enables the overrides (as in wp-config.php). Every constant of upstream's Options::get_const_value() is read from the environment with the same name; overridden fields are shown read-only with "The value of this field was set using a constant." Supported: WPMS_MAILER, WPMS_MAIL_FROM, WPMS_MAIL_FROM_FORCE, WPMS_MAIL_FROM_NAME, WPMS_MAIL_FROM_NAME_FORCE, WPMS_SET_RETURN_PATH, WPMS_DO_NOT_SEND, WPMS_SMTP_HOST, WPMS_SMTP_PORT, WPMS_SSL, WPMS_SMTP_AUTH, WPMS_SMTP_AUTOTLS, WPMS_SMTP_USER, WPMS_SMTP_PASS, every mailer key (WPMS_SENDLAYER_API_KEY, WPMS_SMTPCOM_API_KEY, WPMS_SMTPCOM_CHANNEL, WPMS_SENDINBLUE_API_KEY, WPMS_SENDINBLUE_DOMAIN, WPMS_MAILGUN_API_KEY, WPMS_MAILGUN_DOMAIN, WPMS_MAILGUN_REGION, WPMS_SENDGRID_API_KEY, WPMS_SENDGRID_DOMAIN, WPMS_POSTMARK_SERVER_API_TOKEN, WPMS_POSTMARK_MESSAGE_STREAM, WPMS_SPARKPOST_API_KEY, WPMS_SPARKPOST_REGION, WPMS_AMAZONSES_CLIENT_ID, WPMS_AMAZONSES_CLIENT_SECRET, WPMS_AMAZONSES_REGION, WPMS_GMAIL_CLIENT_ID, WPMS_GMAIL_CLIENT_SECRET, WPMS_OUTLOOK_CLIENT_ID, WPMS_OUTLOOK_CLIENT_SECRET, WPMS_ZOHO_DOMAIN, WPMS_ZOHO_CLIENT_ID, WPMS_ZOHO_CLIENT_SECRET, WPMS_ELASTICEMAIL_API_KEY, WPMS_MAILJET_API_KEY, WPMS_MAILJET_SECRET_KEY, WPMS_MAILERSEND_API_KEY, WPMS_MAILERSEND_HAS_PRO_PLAN, WPMS_RESEND_API_KEY, WPMS_SMTP2GO_API_KEY, WPMS_MANDRILL_API_KEY), logs (WPMS_LOGS_ENABLED, WPMS_LOGS_LOG_EMAIL_CONTENT, WPMS_LOGS_LOG_RETENTION_PERIOD), alerts (WPMS_ALERT_EMAIL_SEND_TO, WPMS_ALERT_SLACK_WEBHOOK_URL, WPMS_ALERT_DISCORD_WEBHOOK_URL, WPMS_ALERT_TEAMS_WEBHOOK_URL, WPMS_ALERT_CUSTOM_WEBHOOK_URL, WPMS_ALERT_TWILIO_SMS_ACCOUNT_SID, WPMS_ALERT_TWILIO_SMS_AUTH_TOKEN, WPMS_ALERT_TWILIO_SMS_FROM_PHONE_NUMBER, WPMS_ALERT_TWILIO_SMS_TO_PHONE_NUMBER), WPMS_SUMMARY_REPORT_EMAIL_DISABLED, WPMS_DEBUG_EVENTS_RETENTION_PERIOD. License, WhatsApp, multisite and one-click constants are not applicable.

14. Left out (not applicable to single-site Pursae)

Multisite network settings, license/upgrade screens and "About Us"/product upsells, usage tracking, WP-CLI commands, the WordPress Abilities API, importing other SMTP plugins' settings, conflicting-plugin detection, attachment storage, open/click tracking, XLSX export, push/WhatsApp alerts, one-click Gmail/Microsoft setup through WPForms' relay.

15. Where it lives

internal/mail/{smtp,api,oauth}.go (transports, AWS SigV4, OAuth 2), internal/mail/smtptest (fake SMTP server for tests), internal/server/mailsmtp*.go (options, delivery, log, alerts, reports, admin screens), web/admin/templates/pages/mailsmtp.html, internal/db/migrations/0011_wp_mail_smtp.sql. Hooks into shared code: mail.Mailer.Transport, Server.mailer() (mailSMTPAttach), the wp_mail_smtp_daily job, the Plugins screen row, pluginAdmin (admin?page=wp-mail-smtp*), adminPage (menu + notices) and the dashboard widget.
