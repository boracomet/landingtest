Plugins overview

How Pursae plugins work — WebAssembly in a sandbox, permissions you approve, signed packages — and what the SDK offers.

A Pursae plugin is a Go program compiled to WebAssembly and packed in a signed zip. The site runs it in a sandbox (wazero, pure Go) and lets it reach the site only through a small host API gated by permissions the administrator approves when activating it.

┌──────────── Pursae ────────────┐      ┌──── plugin.wasm (sandbox) ────┐
│ the_content ──► hooks ───────────────┼─────►│ wpgo.AddFilter("the_content") │
│ [tag] ───────► shortcodes ───────────┼─────►│ wpgo.AddShortcode("tag")      │
│ /wp-json/<slug>/v1/… ► REST routes ──┼─────►│ wpgo.RegisterRestRoute(...)   │
│ Settings › Plugin ◄── settings page ─┼──────┤ wpgo.RegisterSettingsPage()   │
│ jobs table ───► cron_* actions ──────┼─────►│ wpgo.ScheduleEvent(...)       │
│ options, posts, users, storage,      │◄─────┤ wpgo.GetOption, GetPost, …    │
│ transients, HTTP, notices, assets    │      │ (each needs a permission)     │
└──────────────────────────────────────┘      └───────────────────────────────┘

Why Wasm

  • Isolation. A plugin has no filesystem, no sockets, no environment. It sees only JSON messages from the host and can call only the host functions its permissions allow.
  • Containment. A panic, an infinite loop or os.Exit in a plugin is caught: the call times out or fails, the filter keeps its original value, the module is re-instantiated. After five consecutive failures the plugin is disabled and the admin sees why.
  • Portability. One plugin.wasm runs on every platform Pursae runs on. The SDK is Go today (wpgo/sdk/go/wpgo); the ABI is plain JSON, so other languages can follow.

Signing and trust

Packages are signed with Ed25519. A site installs a package only if its signature verifies against a key the site trusts (WPGO_PLUGIN_KEYS or the plugin_trusted_keys option), or if the administrator explicitly allows unsigned packages for development. Plugins published through the Hub are re-signed with the Hub's key, which sites trust automatically. Static files under assets/ are covered by the signature through their digests in plugin.json.
